# Discovr runtime dependencies.

# binary, and a smaller bundle unpacks (and therefore starts) faster.
# Heavy cloud SDKs (azure-mgmt-*, google-cloud-compute + gRPC) were replaced
# by plain REST calls, and optional features are imported lazily at runtime.
