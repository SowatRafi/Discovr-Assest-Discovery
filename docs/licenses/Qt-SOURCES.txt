Discovr uses the unmodified PySide6-Essentials and Shiboken wheels from PyPI.

The USB folder keeps the Qt shared libraries and plugins under _internal/PySide6
(inside Contents/Resources/runtime in the Mac app). You may replace these with
compatible modified builds, or rebuild Discovr from its MIT-licensed source using
your modified Qt/PySide6 installation and the checked-in PyInstaller recipe.
Keep architecture, Python ABI, Qt/PySide versions and plugin versions compatible.
Discovr does not prohibit reverse engineering for debugging such modifications.
