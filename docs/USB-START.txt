DISCOVR - READY TO RUN FROM YOUR USB DRIVE

Copy this WHOLE folder to your USB drive once. Keep its contents together.
Windows: double-click Discovr.exe.
Linux: double-click Discovr (choose Run if your file manager asks).
macOS: use the matching Mac download and double-click Discovr.app.

Discovr opens its own native desktop window. No browser or website is used.
No Python, nmap, capture driver, provider CLI, installer or command is required.
Choose a discovery source, enter its details, and click Start discovery.
AD and cloud sources need your own authorised credentials.

Save inventory keeps every asset as JSON. Export view saves filtered results.
Close the app window or choose File / Quit before ejecting the USB drive.
Discovr offers to save unsaved inventory when you close it.

The runtime loads directly from the folder or Mac app. No temporary extraction or
symbolic-link support is needed. Startup and scans still depend on USB speed and
the network.

These builds are unsigned. Your operating system may ask for approval on first
use. Linux must allow running applications from the USB drive. If needed, use
the file manager's Properties / Permissions / Allow executing file option.
A drive mounted with execution disabled needs an administrator policy change.
Discovr cannot bypass those operating-system restrictions.

Passive observation reads existing neighbour-cache entries. They may be stale,
and devices missing from the cache will not appear. Network OS names are hints,
not exact operating-system verification. No raw packet capture is included.
